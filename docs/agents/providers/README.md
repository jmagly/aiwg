# Provider Operational References

These references contain exact provider-specific commands, paths, automation,
diagnostics, and recovery procedures. For a person's first setup, begin with
the conversational [Install, Connect, and Verify](../../getting-started/install-connect-verify.md)
guide instead.

The preferred complete deployment is:

```bash
aiwg use all --provider <provider>
```

After deployment, reopen the provider and invoke `aiwg-regenerate` in its chat
or command interface so it can connect AIWG to the current project.
