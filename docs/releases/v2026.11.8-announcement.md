# AIWG 2026.11.8 - Cursor as a worker and steadier setup

> Use Cursor for this coding task alongside Codex, check my worker setup before you hand anything off, and look up the right skill before you start.

AIWG 2026.11.8 adds Cursor to the AI tools your assistant can hand work to, fixes several setup problems that showed up once more tools were connected, and makes assistants look things up through AIWG before they start reading files.

## Hand work to Cursor

> Give this coding task to a Cursor worker using one of my plan's models, and tell it where to save the result.

A worker is a separate AI session your assistant gives a task to. AIWG already handed work to Codex and Muse; Cursor now joins them. AIWG reads the models your Cursor plan offers and only uses ones it can name exactly, never Cursor's automatic choice. If it cannot tell how much text a model can take, it tells you which setting to add instead of guessing. For Cursor in the editor, AIWG also installs the same lookup reminder your assistant gets in other tools.

## Catch worker setup problems early

> Check my worker setup and tell me exactly what to change before I hand anything off.

Before this release, a worker group could pass setup checks and then fail only when you tried to use it. The worker health check now lists groups that are not set up for the kind of work you route to them, tools that no group uses, and setups that went stale after a configuration change, each with the exact change to make.

## Look things up before reading files

> Before you answer, find the AIWG skill or template for this and use it.

The instructions AIWG installs for each tool now say plainly: look up the right skill first, then read project files, and never dig through AIWG's copies of skills directly. In checks with Codex, Muse and Antigravity, each started by looking up the skill and loaded it through AIWG.

## Fewer setup surprises

> Refresh AIWG in this project and tell me if anything needs my attention.

- If you set AIWG up both globally and in a project, Claude no longer receives the lookup reminder twice on every message.
- Refreshing a project now repairs older global setups whose hooks stopped working outside your home folder, and warns instead of stopping if you edited one yourself.
- OpenClaw now reads AIWG's project instructions when it works inside a project folder.
- In workspaces with several repositories, the setup check no longer stops early or reports shared boilerplate as duplicate instructions.
- The Codex trust reminder shows once for a trusted project and comes back only when the hook changes.

## Better writing checks

> Check this draft for machine-sounding patterns before I send it.

The writing checker catches a few more patterns, such as a setup that withholds the problem until a punchline, or a run of short sentences that ends in a moral. It now finds 47 of the 56 patterns in its test examples, a figure that describes those examples only. You still decide which suggestions help.

After updating, ask your assistant to refresh AIWG for your tools. See the [full CHANGELOG](https://github.com/jmagly/aiwg/blob/v2026.11.8/CHANGELOG.md#2026118---2026-11-17) for every change.
