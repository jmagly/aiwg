# AIWG 2026.11.7 - Clearer handoffs and more useful writing help

> Find the right template for this task, give any worker clear instructions about where to save its result, and check the writing before handing it back to me.

AIWG 2026.11.7 helps your assistant hand off work more reliably, find useful formats and spot more machine-sounding writing. Updates and previews also spend less time copying files.

## Give workers a clear place to finish

> Give a worker this task and tell it exactly where to save its result. If delegation is refused, explain what needs fixing and retry when it can be fixed.

A worker is a separate AI session your assistant gives a task to. Rendered worker commands now always include the result location and required format, or explain why that route cannot be used. Delegation refusals give specific remedies, including how to fix a worker's working folder or an incomplete delivery request.

## Start with a useful format

> Find the template for a commit message, PR description, status report or worker brief, then use it for this task.

These everyday requests now find the matching default template first when your assistant searches for templates. Eight new templates cover handoffs, reports, reviews and other common outputs, helping your assistant include the information each task needs.

## Catch more repetitive writing

> Check this draft for machine-sounding patterns. For this set of posts, also look for repeated phrases and sentence shapes across documents.

The writing checker catches more stock contrasts, formulaic endings and repeated sentence structures. Headers, code and front matter are excluded from prose checks. It now catches 46 of 56 annotated patterns in its test corpus; that result measures recall on those examples, not accuracy across all writing. You still decide which suggestions improve your draft.

## Spend less time updating

> Update AIWG for my tools and preview the changes. Keep my chosen models and report any broken local bundles.

`aiwg update` reuses its source-file snapshot, and dry-run previews skip that copying altogether. Both do far less file copying, especially helpful on Windows. A partial project model configuration keeps the supplied model pins, and one broken project-local bundle no longer hides valid neighbours.

Releases now require a five-run reproducibility check across all four packages before tagging, comparing their files and packaged downloads for consistency.

After updating, ask your assistant to refresh AIWG for your tools. See the [full CHANGELOG](https://github.com/jmagly/aiwg/blob/v2026.11.7/CHANGELOG.md#2026117---2026-11-16) for every change.
