# AIWG 2026.11.9 - Lookup without copies and steadier tools

> Set up AIWG without copying every skill into my tool's folders, keep my workers working after updates, and search the full text of my larger files.

AIWG 2026.11.9 makes copying bundles a choice, carries existing Windsurf support forward under the Devin name, and fixes problems with workers, search and setup. Writing review can also use the existing decision engine to check patterns by meaning.

## Copying is now opt-in

> Make this framework available for lookup, and only copy it into my tool's folders if I ask.

AIWG already let your assistant look up skills, agents and commands. Now `aiwg use` registers bundles for lookup instead of copying them into your tool's folders. Your assistant finds them with `aiwg discover` and reads them with `aiwg show`. Add `--copy` when you want copies in your tool's folders, for example `aiwg use sdlc --copy`. Existing copies are kept, so updating does not remove the files you already have.

## Windsurf is now Devin

> Refresh AIWG for Devin and keep my existing Windsurf setup working.

AIWG already supported Windsurf; now its help, docs and status use Devin or Devin Desktop. Use `devin` when choosing the tool in a new setup. Existing Windsurf setups keep working: AIWG still recognizes them and writes the folders Devin Desktop currently reads. The older `--provider windsurf` name still works too.

## Writing checks that understand meaning

> Check whether this draft repeats the same sentence structure even when the words are different.

The writing checker already used rules to find patterns. With decision ask enabled, it can now send a possible match to the existing decision engine for a yes-or-no check about its meaning. That helps confirm patterns such as paired statements with matching structure or three fragments in a row. Findings from these checks are labelled model-assisted and include confidence. With decision ask off, the checker works as before.

## Keep handing work to your tools

> Check my workers, then give this coding task to the tool I have set up for it.

AIWG already handed work to these tools; this release updates their connections as the tools change.

- Cursor workers stay usable after cursor-agent updates, with a warning when a build is newer than the ones checked.
- Antigravity workers work with its updated model names and message format.
- Factory workers recognize when droid 1.0.0 finishes a task.
- DeepSeek Harness workers apply the matching permission preset when patched, and can optionally use OpenRouter.
- Grok Build gets AIWG agents compiled into its own agent folder when you add `--copy`.

## Search that finds large files

> Search the full text of my larger files, including the ones the index used to skip.

Full-text search already existed, but the default search backend skipped files larger than 256 KiB. It now stores their full text for search. After updating, run `aiwg index sync` so full-text search covers large files in your existing index.

## Fewer setup surprises

> Refresh AIWG in this project and tell me whether my setup is current.

- Status now checks for outdated deployments against the running version and lists every configured tool, including Muse.
- Refresh marks current managed agents and commands with the running version.
- On Windows, setup checks and refresh work when Node is installed in a path with spaces, such as `C:\Program Files\nodejs`.

After updating, ask your assistant to refresh AIWG for your tools. See the [full CHANGELOG](https://github.com/jmagly/aiwg/blob/v2026.11.9/CHANGELOG.md#2026119---2026-11-22) for every change.
