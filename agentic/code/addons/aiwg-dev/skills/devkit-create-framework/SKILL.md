# Devkit Create Framework

This skill is an alias of the canonical `scaffold-framework` skill in aiwg-utils.
Load and follow its instructions, including guided design and post-creation guidance:

```bash
aiwg show skill scaffold-framework --body
```

```bash
aiwg scaffold-framework <name>
```
